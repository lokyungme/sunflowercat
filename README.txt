SUNFLOWERCAT v67 — CODE-ONLY PATCH

Use this with the full Sunflowercat folder you already have on your computer.

1. Unzip this patch.
2. Open your existing Sunflowercat site folder.
3. Drag index.html and half-mourning.html from this patch into that folder.
4. Choose Replace when macOS asks.
5. Make sure these four image files are also in the SAME main site folder:
   half-mourning-1.jpg
   half-mourning-2.jpg
   half-mourning-3.jpg
   half-mourning-4.jpg

The Half Mourning page expects those exact filenames.

This patch:
- activates the Half Mourning link on the index page
- uses the stable single-image zoom/pan viewer
- keeps the thin top bar
- keeps I / II / III / IV in the top bar

No other site files are changed.
